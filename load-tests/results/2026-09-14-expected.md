Environment: deployed Supabase Edge Function `recommendations` version 17,
Gemini `gemini-3.6-flash`, standard paid tier. The run used dedicated anonymous
test users and synthetic Los Angeles-area prompts; no real user data was used.

## Tuning evidence

The first 10-user/50-search run used default medium thinking. It produced 96%
success, a 4% timeout rate, p95 latency of 17,633.09 ms, 109,211 measured tokens,
and a $1.10960125 lower-bound cost. Four timed-out Gemini calls were unmetered,
so that cost was incomplete and the tier failed.

After configuring the supported `MINIMAL` thinking level and a 2,048-token
output ceiling, the identical tier passed. P95 latency fell 61.7%, measured
token volume fell 77.1%, and estimated cost fell at least 69.0%.

## Scope and remaining limit

This result proves the deployed path through 10 concurrent recommendation
users under the tested request mix. The 25-user peak tier was subsequently
measured in [2026-09-14-peak.md](2026-09-14-peak.md). Provider quotas and
spending caps remain external limits; the function converts their rejection
into typed `UPSTREAM_CAPACITY` responses, opens a 60-second best-effort circuit
breaker, and returns `Retry-After`, but this run did not deliberately exhaust
the paid provider.
