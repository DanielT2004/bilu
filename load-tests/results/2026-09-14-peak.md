## Test-harness correction

An initial peak run used k6 shared iterations and returned 99/100 successes.
Because shared iterations can assign more searches to faster virtual users, the
single pre-Gemini failure could have measured a per-user quota rather than
system capacity. The harness now uses `per-vu-iterations`: each of the 25 users
performed exactly four searches. It also reports authentication, user-quota,
and unexpected failures separately. The clean rerun above is the release
result.

## Scope

This proves the deployed recommendation path through 25 concurrent users for
the tested request mix. The 50-user stress tier was subsequently measured in
[2026-09-14-stress.md](2026-09-14-stress.md). The run observed no Gemini quota
or spending-cap exhaustion, so the provider circuit breaker was not
deliberately triggered.
